# React Test Playground (Next.js)

Next.js port of [React Test Playground](https://react-website-two-rho.vercel.app/) — a DOM playground for automation, accessibility, and manual QA.

## Routes

- `/` — Home
- `/forms` — Forms & Inputs
- `/buttons` — Buttons & Links
- `/iframes` — Iframes
- `/shadow-dom` — Shadow DOM
- `/media` — Media & Graphics
- `/tables` — Tables & Lists
- `/interactive` — Interactive
- `/accessibility` — Accessibility
- `/misc` — Misc Elements

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
